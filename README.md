Temas
1. Requisições HTTP com Retrofit e Kotlin

O Retrofit é uma biblioteca que facilita a comunicação entre um aplicativo Android e servidores através de APIs HTTP.

Proposta

Criar um aplicativo que consuma uma API online utilizando Retrofit.

A API sugerida deve ser substituída por outra API de sua escolha.

Requisitos

Utilizar Retrofit.

Consumir uma API online.

Fazer a requisição através de um botão.

Exibir os dados retornados pela API no aplicativo.

Documentação

Documentação oficial do Android — Conectividade e HTTP

2. Download de imagens com Coil

Coil é uma biblioteca para Android que permite baixar e exibir imagens da internet, realizando o carregamento em segundo plano e utilizando cache.

Proposta

Criar um aplicativo que exiba imagens provenientes da internet.

Requisitos

Criar uma lista com várias imagens.

Utilizar diferentes URLs de imagens.

Exibir as imagens na tela.

Permitir observar o desempenho do carregamento.

Exibir uma frase aleatória na tela de piada.

Documentação

Coil — Documentação oficial

Android — Carregamento de imagens com Compose

3. Permissões em Tempo de Execução

Alguns recursos do celular, como localização, câmera e contatos, precisam da autorização do usuário.

Essa autorização pode ser solicitada enquanto o aplicativo está sendo executado.

Proposta

Criar um aplicativo que solicite a localização do usuário.

Requisitos

Solicitar a permissão de localização em tempo de execução.

Demonstrar o fluxo de solicitação da permissão.

Mostrar o comportamento do aplicativo quando a permissão é concedida.

Mostrar o que acontece quando a permissão é negada ou solicitada incorretamente.

Exibir uma frase aleatória na tela de piada.

Documentação

Android — Solicitação de permissões

4. Intents

Intents permitem que um aplicativo Android se comunique com outros aplicativos e recursos do sistema, como:

Google Maps

Navegador

Discador

Tela de compartilhamento

Proposta

Criar um aplicativo que permita ao usuário pesquisar um local.

Requisitos

O usuário deverá:

Digitar um local, como cidade, monumento, restaurante ou ponto turístico.

Clicar no botão Explorar.

O aplicativo deverá abrir o Google Maps ou navegador, mostrando o local pesquisado.

Exibir uma frase aleatória na tela de piada.

Documentação

Android — Intents e Intent Filters

5. Corrotinas do Kotlin

As corrotinas do Kotlin permitem executar tarefas assíncronas de maneira mais simples e estruturada.

Proposta

Criar um aplicativo que simule um semáforo.

Requisitos

O semáforo deverá alternar automaticamente entre:

Verde

Amarelo

Vermelho

Cada cor deverá possuir um tempo diferente de duração.

Também deverá existir um botão para ativar o modo Amarelo piscante.

Além disso, o aplicativo deverá exibir uma frase aleatória na tela de piada.

Orientações Gerais
1. Comece pelo mais simples

Faça a funcionalidade principal funcionar primeiro antes de se preocupar com aparência e detalhes visuais.

2. Sincronize as dependências

Sempre que adicionar uma biblioteca no build.gradle, clique em Sync Now antes de continuar.

3. Consulte a documentação oficial

Priorize a documentação oficial indicada em cada tema. Tutoriais encontrados na internet podem utilizar versões antigas das bibliotecas.

4. Uso de Inteligência Artificial

Caso utilize alguma ferramenta de IA como apoio:

Não peça o código completo pronto.

Utilize a IA para tirar dúvidas pontuais.

Exemplos:

"Como faço X?"

"O que significa este erro?"

"Por que este código não está funcionando?"

Entenda o código gerado antes de utilizá-lo.

Durante a apresentação, o grupo deverá ser capaz de explicar cada parte do código desenvolvido.

5. Teste antes da apresentação

Teste o aplicativo no emulador antes da apresentação.

Deixe o projeto aberto e funcionando para evitar perda de tempo durante a demonstração.
